# Carlos Lemos — Portfolio v3

Portfolio estático e responsivo, feito com HTML, CSS e JavaScript puro.

## Abrir

Extraia o ZIP e abra `index.html` no navegador, ou rode `python -m http.server 8080` nesta pasta e acesse `http://localhost:8080`.

## Arquivos

- `index.html`: página com portfólio, projetos e experiência.
- `assets/hero-synthwave.gif`: animação de fundo.
- `assets/hero-poster.webp`: imagem estática para quem prefere movimento reduzido ou usa o botão de pausa.
- `curriculo-carlos-lemos.pdf`: currículo fornecido pelo titular.

O fundo pode ser pausado ou retomado. O site respeita `prefers-reduced-motion`.

As descrições de Gestão Lab e Verdinho Eventos foram alinhadas aos produtos do Ecossistema Veloz; não são alegações de autoria individual de todas as funcionalidades.
